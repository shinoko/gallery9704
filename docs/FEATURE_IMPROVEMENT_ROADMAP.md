# 功能改进建议

本文记录 GALLERY9704 后续可考虑的功能改进方向，作为产品功能路线图。本文仅描述建议，不代表相关功能已经实施。

审查日期：2026-08-05。

## P0：筛选与结果可靠性

### 日期范围校验

当开始日期晚于结束日期时，应在日期输入附近显示明确错误，并阻止执行筛选，避免用户只看到无法解释的空结果。

拍摄日期和发布日期应分别校验，并支持一键交换开始、结束日期。

### 筛选状态持久化

将数据类型、关键词、主题、账号、平台、日期范围和排序方式写入 URL 查询参数。

收益：

- 刷新页面后保留当前结果；
- 可以复制链接分享指定筛选视图；
- 浏览器前进、后退能够恢复筛选状态。

### 排序功能

建议提供：

- 发布时间从新到旧、从旧到新；
- 拍摄时间从新到旧、从旧到新；
- 图片数量；
- 账号名称；
- 活动时间线顺序。

## P1：浏览和检索体验

### 跨数据集检索

除“站姐”和“官方”标签外，增加“全部来源”模式，一次检索两个数据集，并在卡片上明确标记数据来源。

### 快捷筛选

建议增加以下快捷入口：

- 未分类活动；
- 缺少拍摄日期；
- 本月发布；
- 指定年份；
- 仅微博或仅小红书；
- 仅包含某位人物；
- 图片数量异常。

### 搜索提示和命中高亮

输入关键词时显示主题、账号和标签建议。在结果卡片中高亮关键词，并展示命中的正文片段，帮助用户理解匹配原因。

### 分组浏览

支持按活动、月份、账号或平台分组。活动分组可以显示封面、日期范围、记录数和图片总数。

可增加独立时间轴视图，用于按拍摄日期浏览活动。

### 空结果引导

筛选无结果时显示可能原因，并提供：

- 清除全部筛选；
- 清除日期条件；
- 切换到全部来源；
- 查看最接近的主题或账号。

## P1：图片查看体验

### 弹窗导航

建议增加：

- 当前记录的缩略图列表；
- 图片缩放和拖动；
- 适应窗口与原始尺寸切换；
- 前后图片预加载；
- 移动端左右滑动；
- 返回当前卡片并保持页面位置。

### 图片操作

可提供下载当前图片、复制原文链接和复制记录信息。批量下载应先明确预计文件数量和大小。

### 选集与收藏

允许用户将记录或图片加入临时选集，并支持：

- 仅查看选集；
- 导出选中记录清单；
- 导出选中图片；
- 为选集添加名称和备注。

如果仅用于单机，可以先使用浏览器本地存储；如果需要跨设备，再设计服务端存储。

## P1：维护模式

### 软删除与撤销

删除记录时先移入回收站，而不是立即删除元数据和图片。回收站应显示删除时间，并支持恢复和彻底清理。

### 修改历史

记录每次修改前后的主题、拍摄日期、标签、备注、修改时间和操作来源。界面提供单条记录历史和撤销入口。

### 批量编辑

当前批量维护可以扩展到：

- 批量设置活动主题；
- 批量设置或清除拍摄日期；
- 批量添加、移除标签；
- 批量修改维护状态；
- 批量移动到回收站。

提交前应显示变更预览，避免大范围误操作。

### 数据质量面板

增加维护仪表板，集中展示：

- 未分类记录；
- 缺少拍摄日期；
- 缺少平台原始 ID；
- 疑似重复记录；
- 图片数量字段不一致；
- 图片路径格式异常；
- 源数据和生成数据不一致。

每项应支持直接进入对应筛选结果。

### 保存状态反馈

用页面内状态提示替代大量 `alert`：保存中、保存成功、部分失败和重试入口。页面离开前应提示尚未保存的修改。

## P2：导入与导出

### 导入预览

正式导入前展示报告：

- 新增记录；
- 已存在记录；
- URL 或平台 ID 冲突；
- 缺图记录；
- 非法日期和未知平台；
- 将被覆盖或删除的内容。

用户确认后再执行提交。

### 按筛选结果导出

静态导出可以支持：

- 仅导出当前筛选结果；
- 仅导出某个活动或年份；
- 是否包含原文和维护字段；
- 生成只读分享版。

### 数据统计报告

提供记录数量、图片数量、账号覆盖、年份分布、平台分布、未分类比例和最近更新时间等统计。

## P2：可访问性和键盘操作

建议完善：

- 自定义下拉菜单的上下方向键、Home、End 和 Esc 操作；
- 日期选择器焦点移动和焦点返回；
- 图片弹窗焦点锁定；
- 图片替代文本；
- 颜色对比度和减少动画偏好；
- 屏幕阅读器可读的结果数量变化提示。

## P3：可选增强

- 离线浏览和 PWA 缓存；
- 多语言界面；
- 活动封面自动选择；
- 相似图片或疑似重复图片辅助检查；
- 账号和活动的独立详情页；
- 跨设备同步收藏与选集。

这些功能应放在数据可靠性、维护安全和基础检索体验完善之后。

## 推荐路线

### 第一阶段：可靠易用

1. 日期范围校验。
2. URL 保存筛选状态。
3. 排序与快捷筛选。
4. 软删除和保存状态反馈。
5. 数据质量面板。

### 第二阶段：高效浏览和维护

1. 跨数据集检索。
2. 搜索建议与高亮。
3. 活动分组和时间轴。
4. 批量编辑与修改历史。
5. 导入预览。

### 第三阶段：增强体验

1. 图片缩放、缩略图导航和选集。
2. 按筛选结果导出。
3. 统计报告。
4. 离线能力和其他可选增强。
